# materials_for_mc_online

Demonstration of [Materials_for_MC](https://github.com/fusion-neutronics/materials_for_mc) Web Assembly capabilities.

Materials_for_MC supports WASM composition targets, when compiled to WASM the
package can be accessed from a HTML webpage.

This repository hosts the webpage content and the online website can be accessed here. [https://fusion-neutronics.github.io/materials_for_mc_online/](https://fusion-neutronics.github.io/materials_for_mc_online/)


```bash
python -m http.server 8000
```
